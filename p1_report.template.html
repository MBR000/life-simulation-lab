EXPERIMENT P1_ABROAD / 2002 年出生

出国，还是留下？

同样的出生条件，分别执行「积极寻找出国机会」和「倾向留在本国」。收入、财富与寿命，会走向哪里？

比较的是两种策略的完整人生结果。积极出国不等于成功移民，留在本国策略也不保证从未出境。

先看结论：收入上升，不等于资产更多

中国组：40 岁收入高，积累少

积极出国组月均收入中位数 10,274 元，留在本国组 6,362 元；净资产中位数却是 28.5 万元 对 49.9 万元。

两臂分别有 935 / 948 个 40 岁快照。这里比较各臂存活者的中位数，不是同一个人的收入增幅；也不能仅凭这些数据把资产差异归因于某项开支。

国家环境决定方向

美国组的 40 岁月均收入中位数由 17,719 元降至 11,946 元。五组的积极出国者净资产中位数均更低，收入方向却不一致。

没有「出国必赚」的统一结论。结果来自模型 0.8.30 的规则，不构成现实移民建议或未来收入预测。

01 / 策略真的改变了居住地吗？

年度状态中曾出现出生国以外居住地的比例。分母固定为每臂全部 1,000 人，包含未成年死亡者；短期、年内往返可能漏记。

如何理解两条路径

积极出国 seek：遇到相关选项优先尝试申请或前往；18 岁起还会尝试设置出国计划。机会、预算和冷却条件仍由游戏控制。

留在本国 avoid：相关选项优先留下或不出国，不主动设置上述计划。其他事件仍可能改变国家。

中国组曾在国外居住的比例为 81.4% vs 0.5%；尼日利亚为 34.8% vs 4.9%。策略实际覆盖率差异很大。

这里只比较事先分配的策略。不能筛出成功移民者后，把他们与所有未移民者的差距直接当作出国效果。

展开：策略触达、实际改选与计划尝试

触达＝记录了 policy:abroad 决策；改选＝至少一次 picked 与 auto 不同；计划尝试＝记录了 moveplan:abroad 动作。一次计划动作不等于成功移民。触达与计划人数有重叠。

02 / 到这个年龄，有多少人民币？

金额换算：内部购买力单位 × 3.5，按游戏中国大陆人民币口径显示。不是市场汇率或现实购买力预测；月均收入＝年度收入 ÷ 12，不是到手工资。净资产包含现金、投资、房产与持有企业价值，可能为负。

P10–P90 为各臂人群的分布范围，非置信区间。固定年龄仅纳入有该年龄快照者；「终生末次」为每人死亡时快照，年龄不同。净资产倍数＝净资产 / 当地年收入中位数，并非当地净资产中位数。

收入随年龄变化

绿色：留在本国 · 橙色：积极出国。各年龄存活样本不同，曲线不是固定人群的个人成长轨迹。

03 / 同起点，也可能走出很远

策略比较保持相同种子，但决策变化会改变后续事件和随机数消耗。N2 则在无策略条件下，出生后跳过一次随机抽样，让未来走向另一条路径。它衡量路径敏感性，不能从策略差中直接扣除。

策略差＝seek − avoid；N2 差＝burn1 − burn0。固定年龄各自在两臂均有快照的种子上配对，因此 N 不一定相同。平均绝对差描述个体路径分歧，均值区间描述群体平均差；两者不能混用。N2 不是在 seek/avoid 各臂上重复运行的误差估计。

04 / 把统计放回一对人生

每国选一对：在双方均有 40 岁快照的样本里，40 岁净资产倍数差最接近该国配对中位差。避免只挑最戏剧化的故事；也不代表所有人的典型人生。

05 / 数据、异常与复算边界

  • 引擎 0.8.30；出生年份 2002；persona=true；每国使用相同的 P-000001…P-001000。跨国家重复使用种子，不将 5,000 对当作独立全球人口样本。
  • 10,000 条 P1 汇总与原始 gzip 逐一核对，任务 ID 完整、无失败；每对完整出生状态一致。N2 使用已有汇总记录，本次未重新执行引擎。
  • 中国组 P-000877 出生在武汉，9 个月时被美国家庭跨国收养。两条策略均有此经历；汇总国家字段变为美国，但出生状态仍为中国。按指定国家与原始出生状态配对，不能把婴儿期收养算作成年出国策略的成果。
  • 固定年龄比较受生存筛选影响：策略可能改变谁活到该年龄。各臂中位数之差、配对差中位数、配对差均值是不同统计量。
  • 人民币金额不做未来通胀折现。财富分布重尾，均值容易受极端值影响；区间仅作探索性参考，不用于声称真实世界因果关系。
  • 全量记录由 Python 流式解析并统计；报告嵌入汇总和 5 对个案日志，不把所有原始人生交给语言模型归纳。
